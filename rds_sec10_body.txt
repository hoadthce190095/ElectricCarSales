                                                10. Vehicle &amp; Inventory                         10.1 Manage Vehicle                              a. Functional Description                                                                         ID and Name:                                       UC Manage Vehicle                                             Created By:                                  TanPTP                                      Date Created:                                  19/09/2026                                             Primary Actor:                                  Admin                                      Secondary Actors:                                  Manager                                             Description:                                   This use case allows Admin to create, view, update, and manage detailed vehicle information such as brand, model, version, color, VIN, engine number, battery/motor specifications, and price.                                             Trigger:                                   Admin needs to add a new vehicle model/unit or update existing vehicle information.                                             Preconditions:                                   Admin is logged in with vehicle management permission.                                             Postconditions:                                   POST-1: Vehicle information is created/updated in the system.                    POST-2: Changes are reflected in vehicle listings visible to customers and staff.                                             Normal Flow                                   1. Admin navigates to &quot;Vehicle Management&quot;.                    2. Admin selects &quot;Add New Vehicle&quot; or an existing vehicle to edit.                    3. Admin enters/updates vehicle details: vehicle code, origin, manufacturing year, brand, model line, version, color, chassis number (VIN), engine number, batch code, sale price, and battery/motor information.                    4. The system validates that the VIN is unique for new vehicles.                    5. Admin saves the vehicle record.                    6. The system updates the vehicle catalog.                                             Alternative Flows:                                     AF-1: Bulk Import:           Admin imports multiple vehicle records via file upload; the system validates each record before saving.                                             Exceptions:                                     EX-1: Duplicate VIN:           If the entered VIN already exists in the system, the record is rejected with an error message.                                             Priority:                                   High                                             Frequency of Use:                                   Frequent                                             Business Rules:                                   BR1                                             Other Information:                                   Technical specification fields (battery, motor, safety features) are grouped for clarity.                                             Assumptions:                                   None                              b. Business rules                                                                        ID                                       Business Rule                                       Business Rule Description                                         BR1                                  Unique VIN                                  Each vehicle is identified by a unique 17-character VIN (chassis number (VIN)) that never changes throughout its lifecycle.                                            10.2 Import Vehicle                              a. Functional Description                                                                         ID and Name:                                       UC Import Vehicle                                             Created By:                                  TanPTP                                      Date Created:                                  19/09/2026                                             Primary Actor:                                  Admin / Operations Officer                                      Secondary Actors:                                  Supplier                                             Description:                                   This use case allows staff to record the receipt of new vehicle units into inventory (stock-in).                                             Trigger:                                   A new batch/unit of vehicles arrives from the supplier.                                             Preconditions:                                   The vehicle model information already exists, or is created as part of this use case.                    Staff has inventory management permission.                                             Postconditions:                                   POST-1: Vehicle unit(s) are added to inventory with status &quot;Available&quot;.                    POST-2: The import record (stock-in date, supplier, quantity, and location) is stored.                    POST-3: Inventory quantity is updated.                                             Normal Flow                                   1. Staff navigates to &quot;Import Vehicle&quot;.                    2. Staff enters import details: supplier, stock-in date, list of vehicles (VIN, version, color, quantity), and vehicle location.                    3. The system validates VIN uniqueness for each unit.                    4. Staff confirms the import.                    5. The system adds the vehicle unit(s) to inventory with status &quot;Available&quot; and records the import batch (batch code).                                             Alternative Flows:                                     AF-1: Partial Import:           If only part of an expected shipment arrives, staff records only the received units; the remaining units are imported later as a separate batch.                                             Exceptions:                                     EX-1: VIN Already Exists:           The system rejects import of a vehicle unit whose VIN is already recorded.                                             Priority:                                   High                                             Frequency of Use:                                   Frequent                                             Business Rules:                                   BR1, BR4                                             Other Information:                                   None                                             Assumptions:                                   Supplier delivery documentation is available for reference.                              b. Business rules                                                                        ID                                       Business Rule                                       Business Rule Description                                         BR1                                  Unique VIN                                  Each vehicle is identified by a unique 17-character VIN (chassis number (VIN)) that never changes throughout its lifecycle.                                         BR4                                  Import Record Requirement                                  Every vehicle imported into inventory must record stock-in date, supplier, quantity, and vehicle location (Showroom/Warehouse/Yard).                                            10.3 Export Vehicle                              a. Functional Description                                                                         ID and Name:                                       UC Export Vehicle                                             Created By:                                  TanPTP                                      Date Created:                                  19/09/2026                                             Primary Actor:                                  Operations Officer                                      Secondary Actors:                                  Admin                                             Description:                                   This use case allows staff to record a vehicle leaving inventory, typically for handover/delivery to a customer after the sale is completed.                                             Trigger:                                   A vehicle is ready to be handed over to the customer after the sale is completed.                                             Preconditions:                                   The vehicle status is &quot;Sold&quot; and the invoice has been issued.                                             Postconditions:                                   POST-1: The vehicle status is updated to &quot;Delivered&quot;.                    POST-2: The export record (stock-out date, staff in charge, and related transaction) is stored.                    POST-3: Inventory count is updated.                                             Normal Flow                                   1. Staff navigates to &quot;Export Vehicle&quot; and selects the vehicle by VIN or transaction.                    2. The system verifies the vehicle status is &quot;Sold&quot; and that an invoice exists.                    3. Staff confirms handover details (delivery date and recipient).                    4. Staff confirms the export.                    5. The system updates the vehicle status to &quot;Delivered&quot; and updates inventory.                                             Alternative Flows:                                     AF-1: Handover Inspection Failure:           If the vehicle fails a pre-handover inspection, staff can delay export and log the issue for resolution.                                             Exceptions:                                     EX-1: Invoice Not Issued:           The system prevents export if no invoice has been issued for the vehicle's transaction.                                             Priority:                                   High                                             Frequency of Use:                                   Frequent                                             Business Rules:                                   BR5, BR2                                             Other Information:                                   None                                             Assumptions:                                   The vehicle has passed final quality inspection before export.                              b. Business rules                                                                        ID                                       Business Rule                                       Business Rule Description                                         BR5                                  Export Record Requirement                                  A vehicle can only be exported (handed over) when its status is &quot;Sold&quot; and its invoice has been issued.                                         BR2                                  Vehicle Status Flow                                  A vehicle's status follows the sequence: Available → Reserved/Deposited → Documentation in Progress → Sold → Delivered. Status cannot move backward except by authorized correction.                                                 10.4 Update Vehicle Status                              a. Functional Description                                                                         ID and Name:                                       UC Update Vehicle Status                                             Created By:                                  TanPTP                                      Date Created:                                  19/09/2026                                             Primary Actor:                                  Sales Staff / Admin / Operations Officer                                      Secondary Actors:                                  None                                             Description:                                   This use case allows authorized staff to update a vehicle's status as it progresses through the sales process: Available, Reserved, Deposited, Documentation in Progress, Sold, Delivered.                                             Trigger:                                   A business event occurs that changes a vehicle's status (e.g., deposit received, documents completed, sale finalized).                                             Preconditions:                                   The vehicle exists in the system with a current status.                                             Postconditions:                                   POST-1: The vehicle's status is updated and timestamped.                    POST-2: The status change is logged.                                             Normal Flow                                   1. Staff or another use case triggers a status change for a specific vehicle (manually or automatically).                    2. The system validates that the new status is a valid next step in the status flow.                    3. The system updates the vehicle status and records the timestamp and responsible staff.                    4. The system reflects the updated status in vehicle listings and inventory reports.                                             Alternative Flows:                                     AF-1: Automatic Status Update:           Statuses such as &quot;Deposited&quot; (from making a deposit) or &quot;Delivered&quot; (from UC Export Vehicle) are updated automatically by related use cases rather than manually by staff.                                             Exceptions:                                     EX-1: Invalid Status Transition:           The system rejects a status change that does not follow the allowed sequence (e.g., moving from &quot;Available&quot; directly to &quot;Delivered&quot;).                                             Priority:                                   Medium                                             Frequency of Use:                                   Frequent                                             Business Rules:                                   BR2, BR3                                             Other Information:                                   This use case is often invoked internally by other use cases (deposit, contract, invoice, export) rather than accessed directly.                                             Assumptions:                                   None                              b. Business rules                                                                        ID                                       Business Rule                                       Business Rule Description                                         BR2                                  Vehicle Status Flow                                  A vehicle's status follows the sequence: Available → Reserved/Deposited → Documentation in Progress → Sold → Delivered. Status cannot move backward except by authorized correction.                                         BR3                                  Inventory Deduction on Deposit                                  When a vehicle is deposited, the system updates its status to &quot;Deposited&quot; and reduces the number of available-for-sale units in inventory.                                                 10.5 Manage Inventory                              a. Exceptions:                                   None                                             Priority:                                   Medium                                             Frequency of Use:                                   Frequent                                             Business Rules:                                   BR3, BR4                                             Other Information:                                   None                                             Assumptions:                                   None                                                b.
