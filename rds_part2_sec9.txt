9. Inventory                    The Inventory module manages the electric vehicles available in the system. It allows authorized users to monitor vehicle inventory, record vehicle imports, record vehicle exports, and manage the current status of each vehicle.                    The Inventory module consists of four main functions:                         Inventory List                         Import Vehicle                         Export Vehicle                         Vehicle Status                              9.1 Inventory List                         9.1.1 Business Description                    The Inventory List function allows authorized users to view and manage the list of electric vehicles currently recorded in the inventory.                    The system displays vehicle information such as vehicle identification, model, brand, price, quantity, and current status. Users can search, filter, and review vehicle inventory information according to the available criteria.                    This function provides an overview of the current inventory and supports inventory monitoring and management activities.                         9.1.2 Information                                                                Field                               Description                               Required                                     Vehicle ID                              Unique identifier of the vehicle                              Yes                                     Vehicle Name                              Name/model of the vehicle                              Yes                                     Brand                              Vehicle manufacturer/brand                              Yes                                     Category                              Vehicle category/type                              Yes                                     Price                              Selling price of the vehicle                              Yes                                     Quantity                              Number of vehicles currently available                              Yes                                     Import Date                              Date when the vehicle was imported                              Yes                                     Status                              Current status of the vehicle                              Yes                            9.1.3 Business Process                         Authorized user accesses the Inventory List.                         The system retrieves inventory information.                         The system displays the list of vehicles.                         User can search for a specific vehicle.                         User can filter vehicles by available criteria.                         The system displays the corresponding inventory results.                         User selects a vehicle to view its details.                         The system displays detailed vehicle information and current status.                         9.1.4 Alternative Flow                    A1. Search vehicle                         User enters a vehicle name, ID, or other supported search criteria.                         The system validates the search input.                         The system searches the inventory.                         The system displays matching vehicles.                    A2. Filter inventory                         User selects one or more filter criteria.                         The system applies the selected filters.                         The system displays vehicles matching the criteria.                    A3. No matching vehicle                         User enters search or filter criteria.                         The system does not find matching inventory records.                         The system displays an appropriate &quot;No data found&quot; message.                         9.1.5 Exception                    E1. Inventory data cannot be loaded                         The system cannot retrieve inventory information.                         The system displays an error message.                         The user may retry the operation.                    E2. Invalid search criteria                         The system detects invalid input.                         The system asks the user to provide valid search criteria.                         9.1.6 Business Rules                         Each vehicle must have a unique Vehicle ID.                         Only valid vehicle records can be displayed in the inventory.                         Inventory quantity must reflect the current inventory state.                         Vehicle status must correspond to the actual state recorded by the system.                         Users can only perform inventory operations allowed by their assigned permissions.                         Inventory information must be updated after successful import or export operations.                         9.1.7 Data Integrity                         Vehicle IDs must be unique.                         Inventory quantity must not be negative.                         Each inventory record must reference a valid vehicle.                         Vehicle status must be one of the statuses supported by the system.                         Import and export operations must correctly update inventory information.                         9.2 Import Vehicle                         9.2.1 Business Description                    The Import Vehicle function allows authorized users to record vehicles entering the company's inventory.                    When vehicles are received, the user enters the required vehicle and import information. The system validates the information and updates the inventory after the import transaction is successfully completed.                    The import operation increases the available inventory quantity and provides a record of the vehicle entering the inventory.                         9.2.2 Information                                                                Field                               Description                               Required                                     Import ID                              Unique identifier of the import transaction                              Yes                                     Vehicle ID                              Identifier of the imported vehicle                              Yes                                     Vehicle Name                              Name/model of the vehicle                              Yes                                     Quantity                              Number of vehicles imported                              Yes                                     Import Date                              Date of the import transaction                              Yes                                     Supplier                              Supplier providing the vehicle                              No                                     Unit Cost                              Cost of each imported vehicle                              No                                     Total Cost                              Total value of the import transaction                              No                                     Note                              Additional information about the import                              No                                     Created By                              User who created the import transaction                              Yes                            9.2.3 Business Process                         Authorized user selects Import Vehicle.                         The system displays the import vehicle form.                         User enters the required import information.                         The system validates the entered information.                         The system checks the selected vehicle information.                         The system calculates the import information where applicable.                         User confirms the import transaction.                         The system creates the import record.                         The system updates the corresponding inventory quantity.                         The system updates the vehicle status where required.                         The system displays a successful import notification.                         9.2.4 Alternative Flow                    A1. Import an existing vehicle                         User selects an existing vehicle.                         User enters the imported quantity.                         The system validates the vehicle.                         The system increases the inventory quantity after confirmation.                    A2. Import a new vehicle                         User enters the required information for a new vehicle.                         The system validates the vehicle information.                         The system creates the vehicle record where supported.                         The system records the import transaction.                         The inventory is updated.                    A3. User cancels import                         User enters import information.                         User selects Cancel.                         The system discards the unconfirmed transaction.                         No inventory quantity is changed.                         9.2.5 Exception                    E1. Missing required information                         The system identifies missing required fields.                         The import transaction cannot be submitted.                         The system asks the user to complete the required information.                    E2. Invalid quantity                         The system rejects zero or negative import quantity.                         The user must enter a valid quantity.                    E3. Invalid vehicle                         The selected vehicle does not exist or is invalid.                         The system does not create the import transaction.                    E4. Database or system error                         The system cannot save the import transaction.                         The inventory must not be partially updated.                         The system displays an error message.                         9.2.6 Business Rules                         Only authorized users can create import transactions.                         Import quantity must be greater than zero.                         An import transaction must be confirmed before inventory is updated.                         A successful import transaction increases inventory quantity.                         Each import transaction must have a unique Import ID.                         The user who creates the transaction must be recorded.                         The system must not update inventory when the import transaction fails.                         9.2.7 Data Integrity                         Import quantity must be a positive value.                         Import records must reference valid vehicle records.                         Inventory quantity must be updated atomically with the successful import transaction.                         The system must prevent duplicate import transaction IDs.                         Failed import transactions must not change inventory quantity.                         Import information must remain consistent with the corresponding inventory record.                         9.3 Export Vehicle                         9.3.1 Business Description                    The Export Vehicle function allows authorized users to record vehicles leaving the company's inventory.                    An export may occur when a vehicle is sold, transferred, delivered, or otherwise removed from available inventory according to the business process.                    Before completing an export transaction, the system verifies that sufficient inventory is available. After successful confirmation, the system decreases the available inventory quantity and updates the vehicle status where required.                         9.3.2 Information                                                                Field                               Description                               Required                                     Export ID                              Unique identifier of the export transaction                              Yes                                     Vehicle ID                              Identifier of the exported vehicle                              Yes                                     Vehicle Name                              Name/model of the vehicle                              Yes                                     Quantity                              Number of vehicles exported                              Yes                                     Export Date                              Date of the export transaction                              Yes                                     Export Reason                              Reason for exporting the vehicle                              Yes                                     Destination                              Destination or receiving party                              No                                     Note                              Additional information about the export                              No                                     Created By                              User who created the export transaction                              Yes                            9.3.3 Business Process                         Authorized user selects Export Vehicle. User enters the export quantity and required information.                         The system validates the entered information.                         The system checks the available inventory quantity.                         User confirms the export transaction.                         The system creates the export record.                         The system decreases the corresponding inventory quantity.                         The system updates the vehicle status where required.                         The system displays a successful export notification.                         9.3.4 Alternative Flow                    A1.
