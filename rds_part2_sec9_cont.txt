9.3 Export Vehicle                         9.3.1 Business Description                    The Export Vehicle function allows authorized users to record vehicles leaving the company's inventory.                    An export may occur when a vehicle is sold, transferred, delivered, or otherwise removed from available inventory according to the business process.                    Before completing an export transaction, the system verifies that sufficient inventory is available. After successful confirmation, the system decreases the available inventory quantity and updates the vehicle status where required.                         9.3.2 Information                                                                Field                               Description                               Required                                     Export ID                              Unique identifier of the export transaction                              Yes                                     Vehicle ID                              Identifier of the exported vehicle                              Yes                                     Vehicle Name                              Name/model of the vehicle                              Yes                                     Quantity                              Number of vehicles exported                              Yes                                     Export Date                              Date of the export transaction                              Yes                                     Export Reason                              Reason for exporting the vehicle                              Yes                                     Destination                              Destination or receiving party                              No                                     Note                              Additional information about the export                              No                                     Created By                              User who created the export transaction                              Yes                            9.3.3 Business Process                         Authorized user selects Export Vehicle. User creates an export transaction.                         The system verifies available inventory.                         The inventory quantity is reduced after confirmation.                    A2. Export multiple vehicles                         User selects a vehicle.                         User enters an export quantity greater than one. Insufficient inventory                         The requested export quantity is greater than the available quantity.                         The system rejects the transaction.                         The user must reduce the export quantity or select another vehicle.                    E2. Invalid quantity                         The system rejects zero or negative export quantity.                         The user must enter a valid quantity.                    E3. Vehicle unavailable for export                         The vehicle status does not allow export.                         The system prevents the export transaction.                    E4. Database or system error                         The system cannot save the export transaction.                         The system must not partially decrease the inventory. Export quantity must be greater than zero.                         Export quantity must not exceed the available inventory quantity.                         An export transaction must be confirmed before inventory is reduced.                         A successful export transaction decreases inventory quantity.                         Each export transaction must have a unique Export ID.                         The user who creates the transaction must be recorded.                         Failed export transactions must not modify inventory quantity.                         9.3.7 Data Integrity                         Inventory quantity must never become negative.                         Export records must reference valid vehicle records.                         Export quantity must be validated against current inventory.                         Inventory reduction and export transaction creation must be processed consistently.                         Failed transactions must not partially update inventory.                         Each export transaction must be uniquely identifiable.                         9.4 Vehicle Status                         9.4.1 Business Description                    The Vehicle Status function allows authorized users to view and manage the current status of vehicles in the inventory.
